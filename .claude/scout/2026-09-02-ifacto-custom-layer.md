## Verified on Microsoft Learn (2026-09-02)

- **#3** `devenv-permissionset-ext-object`: "adds permissions to an existing permission set defined in AL ... can't remove ... the admin doesn't have to assign extra permission sets to the users, because that automatically happens when the extension is installed, and the permissions go away if the extension is uninstalled." Best practice: "only add permissions for objects, which are part of the application." `devenv-includedpermissionsets-property`: applies to Permission Set and Permission Set Extension, runtime 7.0. Open detail for the author: state `bc-version: [18..]` for the object; note in the article that the target must be an AL-defined set, which every supported Microsoft `D365 *` set is today.
- **#5** `devenv-inherentpermissions-property`: runtime 11.0, applies to Query, Report, XmlPort, Table, Codeunit, Page. `devenv-inherent-permissions`: "After you apply inherent permissions, security administrators can no longer control the permission"; use only where the object does not contain or run on business data.
- **#17** `devenv-job-queue` table "how dialog boxes are handled in a background or web service session": `Dialog.Open` → suppressed, text not displayed or logged; `Dialog.Message` → suppressed, logged; `Dialog.Confirm` → suppressed and the callback error is raised; `Dialog.Error` → execution ends. `clienttype-option` remarks confirm the list of UI methods to guard with `GuiAllowed`.
- **#20** `powerplat-entity-modeling` "Table fields": Enum → Picklist; "generated as global OptionSets ... Matching between the systems is done by using the External Name property of values. Enum integer values in Dataverse aren't guaranteed to be stable ... OptionSet metadata is updated when a table that uses the OptionSet is updated." "Enums" section: "If an OptionSet already exists, it is used instead."
- **#6** `appsourcecop-as0054`: configuration must specify `mandatorySuffix`, `mandatoryPrefix`, or `mandatoryAffixes`. `appsourcecop-as0011`: `mandatoryPrefix` and `mandatorySuffix` "are now both defining an affix that can be used either as prefix or as suffix."
